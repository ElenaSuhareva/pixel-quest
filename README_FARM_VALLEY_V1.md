# Фермерская долина V1

Добавлено:
- страница описания `/games/farm-valley/` по структуре первой игры;
- игра `/games/farm-valley/play/`;
- тема: «Окончания существительных»;
- 20 простых заданий, порядок перемешивается при каждом новом прохождении;
- в одном прохождении используются 10 заданий — по одному на каждую грядку;
- 10 кликабельных грядок;
- после ответа показывается «Верно!» или «Ошибка!» и правильный ответ целиком;
- после «Понятно» фермер поливает выбранную грядку, затем вырастает один из трёх цветов;
- за каждый выращенный цветок сразу начисляется 1 алмаз в общий профиль игрока;
- счётчик 0/10 цветов и алмазов;
- общие кнопки дом / пауза / звук и общий алмаз из `public/assets/common-ui/`;
- финальная панель с количеством цветов, правильных ответов и алмазов;
- ответы в задании можно выбирать стрелками ← → и подтверждать Enter;
- Enter на экране результата работает как «Понятно».

Распаковать содержимое архива в корень `PixelQuestSiteBase` с заменой файлов.
