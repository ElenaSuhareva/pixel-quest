# Храбрый рыцарь V4

Исправления:
- восстановлен промежуточный экран описания игры;
- кнопка «Играть» на главной ведёт на описание, а кнопка «Играть» на описании — в саму игру;
- добавлена картинка с правилами;
- тема указана явно: «Буквы З / С на конце приставок»;
- кнопка «На главную» теперь сделана на той же графической основе, что пауза;
- у кнопок «На главную», «Звук» и «Пауза/Продолжить» появились подписи при наведении;
- каждый собранный и подтверждённый алмаз сразу добавляется в общий счёт игрока в localStorage;
- возврат из игры на главную теперь идёт через Next.js router без полной перезагрузки;
- WelcomeScreen ждёт чтения localStorage, поэтому приветственный экран не должен мигать при возврате.

Установка:
распаковать содержимое архива в корень PixelQuestSiteBase с заменой файлов.
