# Pixel Quest — «Храбрый рыцарь» V1

Готовая первая версия игры для существующего проекта Pixel Quest.

## Что уже работает

- движение: ← / → или A / D;
- прыжок: ↑ / Space / W;
- прыжок вперёд при одновременном движении;
- 3 стартовые жизни, максимум 5;
- пустые и полные сердечки в HUD;
- сердечки на уровне пополняют жизнь;
- шипы и два типа движущихся врагов;
- враги движутся справа налево;
- деревянные и травяные платформы;
- 10 алмазов;
- при каждом алмазе игра ставится на паузу и открывается задание;
- задания: З / С на конце приставок;
- выбор кнопкой З или С;
- после ответа показывается «Верно / Неверно» и правильное слово целиком;
- продолжение только после кнопки «Понятно»;
- пауза / продолжить;
- звук вкл / выкл;
- замок в конце уровня;
- финальный экран;
- лучший результат хранится в localStorage;
- игра не требует сервера/API и подходит для статического экспорта GitHub Pages.

## Установка

Распаковать содержимое архива в корень:

C:\projects\PixelQuestSiteBase

и согласиться на замену `app/games/brave-knight/page.tsx`.

Остальные файлы новые.

После копирования:

1. остановить dev-сервер, если он запущен;
2. `npm run dev`;
3. открыть `http://localhost:3000/games/brave-knight`;
4. после проверки остановить сервер и выполнить `npm run build`.

## Важно

Это V1. Здесь сознательно нет сложного игрового движка, сложных анимаций, боссов и длинного уровня.
Сначала проверяем:
- удобно ли двигается герой;
- нормальна ли высота прыжка;
- хорошо ли расположены препятствия;
- нравится ли окно задания;
- удобно ли проходить короткий уровень.

После проверки V1 можно точечно полировать физику и расположение объектов.
