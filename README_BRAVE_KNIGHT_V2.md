# Храбрый рыцарь — V2

Изменения после первого теста:

- использованы обрезанные пользователем ассеты из `brave-knight.zip`;
- полностью удалены обе картинки-платформы и весь код платформ;
- герой, алмазы, сердечки, враги и UI увеличены;
- земля переработана: вместо большой ровной коричневой полосы сделана более низкая лесная кромка с травой, тёмной почвой и природной текстурой;
- прыжок заметно выше и длиннее;
- скорость движения немного увеличена;
- hitbox героя уменьшен относительно картинки;
- hitbox шипов уменьшен, поэтому препятствия можно честно перепрыгнуть;
- hitbox врагов также чуть мягче;
- все 10 алмазов теперь расположены на высоте, доступной обычным прыжком без платформ;
- сохранены 3 стартовые жизни, сердечки, задания З/С, пауза, звук, замок и рекорд.

Установка: распаковать архив в корень PixelQuestSiteBase с заменой файлов.
Затем остановить dev-сервер и снова выполнить `npm run dev`.
