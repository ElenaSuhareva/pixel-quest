PIXEL QUEST — готовая главная страница

1. Открой папку этого архива.
2. Скопируй ВСЁ содержимое в корень твоего проекта:
   C:\projects\PixelQuestSiteBase
3. Согласись на замену файлов.
4. Проверь app/layout.tsx. Там уже должна быть строка:
   import "@/styles/home.css";
   Если она есть — ничего не меняй.
5. Запусти/оставь запущенным:
   npm run dev
6. Обнови localhost:3000.

Что готово:
- тонкая полупрозрачная шапка;
- логотип слева;
- аватар, имя и алмазы справа в одну строку;
- фон из референса;
- баннер «Добро пожаловать, юный герой!»;
- три разные игровые карточки;
- кнопки «Играть» являются картинками;
- hover/active-анимация кнопок и карточек;
- клик по «Играть» ведёт на отдельную страницу описания игры;
- адаптация под узкий экран.

Главная страница использует существующий профиль из localStorage,
поэтому приветственный экран, который мы сделали раньше, не нужно менять.
