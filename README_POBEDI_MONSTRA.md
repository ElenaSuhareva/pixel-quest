# Мини-игра 3 --- «Победи монстра»

## Идея

Игрок попадает в пещеру и вызывает монстра на битву в крестики-нолики.

Но каждый ход нужно заслужить: перед тем как поставить свой знак на
поле, игрок решает задание по русскому языку.

Правильный ответ --- клетка открывается, игрок ставит свой знак и
получает алмаз.

Неправильный ответ --- ход пропускается.

После хода игрока монстр делает свой ход.

------------------------------------------------------------------------

## Название

**Победи монстра**

------------------------------------------------------------------------

## Описание для страницы игры

Сыграй в пещерную игру крестики-нолики.

Решай задания по русскому языку, получай алмазы и победи монстра!

------------------------------------------------------------------------

## Основная механика

### Игровое поле

-   Поле 3×3.
-   Игрок --- свой знак (например, ✨ или меч).
-   Монстр --- свой знак (например, лапа монстра).
-   Цель --- собрать линию из трёх своих знаков.

------------------------------------------------------------------------

## Ход игрока

1.  Игрок нажимает на свободную клетку.
2.  Открывается задание.
3.  Игрок выбирает ответ.
4.  При правильном ответе:
    -   клетка занимает знак игрока;
    -   начисляется 1 алмаз;
    -   ход передается монстру.
5.  При ошибке:
    -   клетка остается свободной.

------------------------------------------------------------------------

## Ход монстра

После успешного хода игрока монстр случайно выбирает свободную клетку.

Для первой версии без сложного ИИ.

------------------------------------------------------------------------

## Задания

Для первой версии:

-   20 заданий в базе.
-   В каждой игре выбираются случайные.
-   Используются только понятные слова.

Примеры тем: - окончания существительных; - приставки; - безударные
гласные; - другие темы 5--7 класса.

------------------------------------------------------------------------

## Экраны игры

### 1. Страница описания

Содержит:

-   название;
-   краткое описание;
-   картинку монстра в пещере;
-   кнопку «Играть».

------------------------------------------------------------------------

### 2. Игровой экран

Минимальный вариант:

-   фон пещеры;
-   панель алмазов;
-   поле крестики-нолики;
-   кнопки управления.

------------------------------------------------------------------------

### 3. Окно задания

Появляется после выбора клетки.

Содержит:

-   слово или вопрос;
-   варианты ответа;
-   кнопки ответа.

------------------------------------------------------------------------

### 4. Финальный экран

После окончания игры:

Варианты:

-   Победа!
-   Монстр победил.
-   Ничья.

Показываем:

-   результат;
-   количество алмазов;
-   кнопки:
    -   сыграть ещё раз;
    -   к списку игр.

------------------------------------------------------------------------

## Визуальный стиль

Минимум новых ассетов.

Использовать общий стиль сайта:

-   пиксельная графика;
-   синие игровые кнопки;
-   панели из существующего набора;
-   общий счетчик алмазов.

Новые картинки:

1.  Фон пещеры.
2.  Монстр.
3.  Игровые знаки.

------------------------------------------------------------------------

## Почему игра подходит

Игра быстрее в разработке:

-   нет движения персонажа;
-   нет физики;
-   нет сложных анимаций;
-   мало экранов;
-   легко добавлять новые темы заданий.

При этом остается игровая мотивация: решил задание → сделал ход →
победил монстра.
