# Храбрый рыцарь V9

Последняя музыкальная правка:

- фоновая музыка Castle Pathways НЕ останавливается, когда открывается задание;
- при обычной паузе фоновая музыка останавливается;
- на финальном экране игровая музыка останавливается;
- на финальном экране запускается отдельная короткая победная мелодия;
- победная мелодия создана специально для проекта как короткий радостный пиксельный фанфарный джингл;
- кнопка звука управляет и основной музыкой, и победной;
- при «Сыграть ещё раз» победная музыка сбрасывается.

Распаковать содержимое архива в корень PixelQuestSiteBase с заменой файлов.
