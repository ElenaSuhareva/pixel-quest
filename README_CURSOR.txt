PIXEL QUEST — ГЛОБАЛЬНЫЙ ПИКСЕЛЬНЫЙ КУРСОР

Что добавлено:
- зелёно-золотая пиксельная стрелка;
- над ссылками, кнопками, полями и другими интерактивными элементами превращается в руку с пальцем;
- короткий зелёно-золотой шлейф из 6 пиксельных искр;
- искры исчезают примерно за 0,43 секунды;
- работает глобально через app/layout.tsx;
- не использует сторонние библиотеки;
- автоматически отключается на телефонах/планшетах и устройствах без точной мыши;
- учитывает prefers-reduced-motion: при нём шлейф отключается;
- пути к PNG проходят через существующий assetPath(), поэтому совместимы с /pixel-quest на GitHub Pages.

УСТАНОВКА:
1. Распаковать архив в корень C:\projects\PixelQuestSiteBase
2. Выбрать «Заменить файлы в папке назначения».
3. Выполнить npm run dev для визуальной проверки.
4. Затем npm run build перед публикацией.
