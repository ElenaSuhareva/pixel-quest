# Храбрый рыцарь V8

Финальная полировка первой игры:

- добавлена фоновая музыка `Castle Pathways.mp3`;
- музыка играет тихо, зациклена и связана с кнопкой звука;
- на паузе, экране поражения и экране победы музыка останавливается;
- в нижней подсказке теперь написано `Пробел прыжок`;
- выбранная буква З/С сильнее подсвечивается по краям;
- кнопка `Понятно` тоже подсвечена и подтверждается Enter;
- в меню паузы можно выбирать пункт стрелками и подтверждать Enter;
- на экране поражения и победы можно выбирать пункт стрелками и подтверждать Enter;
- наведение мышью синхронизирует текущий выбранный пункт.

Установка:
распаковать содержимое архива в корень PixelQuestSiteBase с заменой файлов.
