# Pixel Quest — «Храбрый рыцарь» V3

Исправления по тесту V2:

- прыжок стал выше и немного длиннее;
- зона столкновения со шипами существенно уменьшена;
- если герой уже поднялся над землёй, визуальный край шипов не отнимает жизнь;
- 10 алмазов расставлены значительно реже;
- уровень немного удлинён, чтобы между заданиями оставалась игровая часть;
- стартовая деревянная стрелка опущена к поверхности;
- враги больше не патрулируют туда-сюда и не возвращаются назад;
- враг активируется, когда герой подходит, затем постоянно движется справа налево и уходит за экран;
- нижняя поверхность стала тонкой лесной кромкой, без большой коричневой стены;
- платформы по-прежнему не используются.

## Проверка

Распаковать архив в корень PixelQuestSiteBase с заменой файлов.
Если dev-сервер запущен, сначала Ctrl+C, затем npm run dev.
Проверять страницу /games/brave-knight.

Дополнительно: первый шип отодвинут дальше от старта, прыжок ещё более прощающий, а враги появляются в движении только при приближении героя и после этого уходят влево без возврата.
